# 哥谭夜行（Gotham Nights）

一个单文件的哥谭市文字冒险游戏：你是哥谭的普通人，可以选择正义线与罗宾、蝙蝠侠并肩，也可以堕入犯罪线投靠小丑，直到迎来属于你的结局。

## ✨ 功能特性

- **双模式游玩**：经典模式为离线可玩的固定剧本；AI 主持人模式由云端大模型实时生成剧情，支持自由文本输入行动
- **善恶双线成长**：正义值 / 犯罪值两条数值线，罗宾、蝙蝠侠、戈登警探、小丑等角色随数值阈值依次登场互动
- **生存数值系统**：生命值与精神值双重约束——死于街头或疯进阿卡姆都是真实结局
- **多结局**：传说守护者、小丑继承人、阿卡姆住户、平凡之光等多种结局分支
- **场景配图**：内置 11 张哥谭场景与角色插图，随剧情切换展示
- **访客统计**：按 IP 哈希去重记录访客数与累计夜行次数（云端数据库）

## 🚀 使用方法

- 本地直接用浏览器打开 `index.html` 即可开始（经典模式完整可玩；AI 模式依赖云端网关）
- 项目含 GitHub Pages 部署工作流，镜像站会提示并自动跳转官方版（AI 模式需在官方域名游玩）

## 🛠️ 技术栈

- 纯 HTML / CSS / JavaScript，零构建、单文件
- WorkBuddy Cloud SDK（云端 LLM 主持人 + 云数据库），多 Flash 模型池轮换与故障转移
- GitHub Actions（Pages 自动部署）

## 📁 目录结构

- `index.html` — 游戏本体（界面、剧本、AI 主持逻辑）
- `assets/` — 场景与角色插图
- `.github/workflows/` — Pages 部署工作流
